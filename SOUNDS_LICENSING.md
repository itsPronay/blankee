## Origin

The original sound selection of this app comes from [Blanket](https://github.com/rafaelmardojai/blanket) by Rafael Mardojai CM
(GPL-3.0, same license as this app), whose sounds were prepared by Porrumentzio. The audio files now shipped are Blankie's
loop-edited versions of the same recordings (see above). Blanket's own licensing table is at
[SOUNDS_LICENSING.md](https://github.com/rafaelmardojai/blanket/blob/master/SOUNDS_LICENSING.md).

## Icons

All sound icons are original vector drawings made for this project (`app/src/main/res/drawable/`), released under the same
